What you still need to do in Shopify admin

The theme is complete and self-consistent, but three things live in your store, not the code:

1. Create the product

  • Add one product with the handle ai-shopify-business-bootcamp, price ₹2,999 and compare-at ₹5,000.
  • Turn on Track quantity and set the real seat count — the "Only N seats left" chip reads it.
  • Paste the course description; the product page and schema use it.
  • If the handle differs, change it in Theme settings → Course product instead of in code.

2. Settings → Policies

  • Publish Refund, Privacy and Terms. The footer, contact page and checkout then link to them automatically (they're required for Meta/Google ad approval and gateway KYC).
  • Add WhatsApp number, Instagram, support email and logo in Theme settings.
  • Set Cohort start date so the countdown is truthful, and pick an accent colour.

3. Add your real proof

  • Replace the three placeholder testimonials with real student quotes, names and photos.
  • Add 2–4 student-store screenshots in the results row.
  • Upload the workshop video and instructor photo — both sections have designed fallbacks until then.
  • Set the social share image (1200 × 630) for WhatsApp link previews.

Install

  • Shopify admin → Online Store → Themes → Add theme → Upload zip → ai-shopify-business-bootcamp-v13.zip.
  • Preview first (the theme is safe to publish immediately, but the product must exist for the buy buttons to work).
  • Then Publish. Full step-by-step notes are in THEME_SETUP.md.
