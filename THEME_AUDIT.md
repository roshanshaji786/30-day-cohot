### 🧭 USER-FRIENDLY / UX — 3.7 / 10

#### 5. Navigation & information architecture — **2 / 10** 🔴
- **9 of 14 links render `href=""`** (4 nav + 1 header CTA + 4 footer). The schemas define default *labels* but no
  default *URLs*, so out of the box every one of them just reloads the page. The header CTA reads **"Join ₹2,999"** and
  does nothing.
- Nav labels promise Program / Curriculum / Instructor / FAQ but **no `id` anchors exist** in `main-course.liquid` —
  even once a merchant sets `#curriculum`, there is nothing to scroll to.
- `@media(max-width:900px){.desktop-nav{display:none}}` — **nav vanishes on mobile with no hamburger, drawer or chip
  row to replace it.** The mobile user has zero wayfinding.
- No cart icon, no search, no breadcrumbs, no secondary CTA in the header on scroll.

#### 6. Readability, content & visual polish — **5 / 10** 🟠
- Structure is right: one `<h1>`, six `<h2>`s, and a logical narrative
  (hero → demo video → outcome → academy → curriculum → trainer → inclusions → price → FAQ).
- **`.eyebrow` has no base CSS rule.** `course.css` only contains `.final-cta .eyebrow{color:#e5e1ff}` (a section that
  doesn't exist in the markup) and a mobile `.eyebrow{font-size:11px!important}`. So every small label
  (FOUNDING COHORT · FIRST 25 STUDENTS, SEE IT IN ACTION, YOUR TRAINER…) renders as ordinary 16px black body text on
  desktop — the intended letterspaced micro-label styling is simply missing.
- `.hero h1 span{color:#7657e8}` never applies — the H1 contains no `<span>`, so the accent word is lost.
- `.mini-curriculum` is used in markup but **never styled** in CSS.
- No `<h3>` anywhere → flat heading hierarchy for screen readers and SEO.
- **Hardcoded content:** curriculum bands, inclusions, hero credentials (`CET Graduate · M.Tech · Featured in ANI`),
  hero meta (`15 Live Classes / Oct 1, 2026 / 9 PM / Google Meet`), all three FAQs and the trainer sub-line are literal
  text in Liquid, not theme-editor settings — contradicting the README's "Theme Editor / Sidebar" promise. Every copy
  change (e.g. the next cohort's date) needs a code edit.
- The meta description in `theme.liquid` is hardcoded, so every page on the store shares one description.

#### 7. Accessibility (WCAG 2.2 AA) — **4 / 10** 🟠
Good: skip link, landmark elements, `aria-label` on brand and `<nav>`, `aria-hidden="true"` on decorative CSS art,
native `<details>` accordions, instructor `alt` text sourced from the name setting, `prefers-reduced-motion` block,
`lang="{{ request.locale.iso_code }}"`.
Gaps:
- **No `:focus-visible` styling anywhere** — keyboard users get only the UA default (and the skip link is positioned at
  `left:-9999px` with `top` only set on focus).
- Text as small as **9px** (`.proof-items`, `.trainer-badge` at ≤600px) and 11px badges — below any readable minimum.
- `.hero-price s{opacity:.55}` on `#111` over `#f8f8f5` ≈ **3.4:1**, under the 4.5:1 requirement; `.desktop-nav a` at
  `#666` on `#fafafa` is borderline.
- Header CTA tap target ≈30px high (`padding:10px 16px`, 13px font) — below the 44×44px minimum.
- In the default state, `.video-placeholder` and `.trainer-photo` are **empty boxes with no accessible name or fallback
  content** — a screen reader announces nothing where the core demo and the trainer's face should be.
- Autoplaying, looping video with `controls` and no pause affordance outside the native controls.

### 📱 MOBILE OPTIMISATION — 3.7 / 10

#### 8. Mobile layout correctness — **5 / 10** 🟠
The `@media(max-width:749px)` V12 block is competent: hero becomes `display:flex;flex-direction:column`, the
illustration drops to `order:2`, H1 clamps to `clamp(38px,10.7vw,52px)`, grids collapse to 1 column, the video caps at
`min(82vw,340px)` / `max-height:600px`, `overflow-wrap:anywhere` prevents text blowout, and `body{overflow-x:hidden}`
kills horizontal scroll.
But:
- **Desktop is broken.** All container width and section padding lives under `.bootcamp-v10`:
  `.bootcamp-v10{max-width:1180px;margin:auto}` and `.bootcamp-v10 section,.bootcamp-v10 header{padding:52px 24px}` —
  while the markup wrapper is `<div class="bootcamp-v12">`. **Those rules never match.** On any viewport ≥750px the
  sections have **zero padding** (text touches the screen edges) and **no max-width** (the hero grid and the 4-column
  inclusions row stretch to the full monitor width). The only desktop padding rules that fire are on `.hero`,
  `.academy-strip` and inside mobile media queries.
- **5 stacked rewrite layers** (V6 mobile-first, V7, V10 compact, V12 QA, V12 photo-fix) with **107 `!important`
  declarations** and three competing breakpoints (**900px / 749px / 600px**) that override each other — e.g. the 900px
  block sets `.steps{grid-template-columns:1fr 1fr}` for classes that no longer exist, while the 749px block re-declares
  hero padding with `!important`.
- The "hero overlap fix" is a band-aid: it sets `.compact-hero .hero-illustration{opacity:.5!important}` on mobile, so
  the artwork looks deliberately faded/washed out rather than correctly laid out.
- `.video-section .video-placeholder{aspect-ratio:9/16}` reserves ~600px of the mobile viewport for the video box —
  before the visitor has seen curriculum, trainer or price detail.

#### 9. Mobile performance & media weight — **4 / 10** 🟠
Good: **zero** third-party scripts, zero webfonts, zero JS files; `aspect-ratio` on media prevents CLS;
`loading:'lazy'` on the instructor image; `image_tag` auto-emits `width`/`height` + `srcset`; `preload:'metadata'` and
`playsinline` on video. (Note: Shopify's `video_tag` already outputs `playsinline`, `preload="metadata"` and an
automatic `poster` from the video thumbnail, so those two params are redundant.)
Bad:
- `assets/course.css` is **23.5 KB unminified, and 73 of its 119 defined classes are dead** — `hero-card`,
  `hero-card-bottom`, `hero-grid`, `hero-lead`, `steps`, `method-grid`, `tool-grid`, `tool-card`, `curriculum`,
  `class-row`, `class-number`, `plus`, `instructor-grid`, `portrait-placeholder`, `pricing`, `pricing-card`, `price-box`,
  `old-price`, `award-grid`, `final-cta`, `faq`, `proof-strip`, `proof-items`, `two-col`, `check-grid`, `included-grid`,
  `illustration`, `bubble`, `screen`, `trainer-credentials`, `media-proof`, `lead`, `signature`, `play`, `journey`,
  `mini-label`, `section`, `section-dark`, `section-soft`, `centered`, `card`, `cards`, `grid`, `badge`, `pill`,
  `nav`, `header-nav`, `header-inner`, `site-footer`, `course-hero`, `hero-section`, `hero-visual`, `hero-art`,
  `visual-break`, `illustration-break`, `desktop-only`, `button`, `button-primary`, `price-card`, `curriculum-grid`,
  `curriculum-card`, `included-card`, `section-title`, `instructor-section`, `bar`, `line`, `short`, `one`, `two`,
  `three`, `bootcamp-v10` — roughly 60% of the stylesheet is leftover from earlier versions. Cleaning + minifying
  takes it to ~7 KB.
- Instructor image requested at `image_url: width: 800` but displayed in a **280px** square (300px mobile); logo
  requested at `width: 280` but displayed at `max-height:34px`. No `sizes` attribute is passed to `image_tag`, so the
  browser assumes `100vw` and downloads the largest candidate on a small phone.
- `backdrop-filter:blur(18px)` on the sticky header is one of the most expensive mobile compositing operations and runs
  on every scroll frame on low-end Android.
- Autoplay + loop on a full workshop video on mobile data, with no size cap, no data-saver guard and no tap-to-play
  fallback. (`loop:true` also disables Shopify's HLS `m3u8` source, forcing a progressive MP4 download.)

#### 10. Mobile conversion ergonomics — **2 / 10** 🔴
- **No sticky bottom buy bar** — the single highest-ROI mobile element for a course landing page.
- The header CTA is dead (`href=""`), leaving only **2 CTAs across ~8 screens of scrolling**.
- The empty 9:16 video box dominates the first screen below the hero in the default state.
- **`.video-placeholder{aspect-ratio:9/16}` + `object-fit:cover` will destroy a landscape workshop recording.** A
  screen-share or slide-based workshop is 16:9; cropping it into a 9:16 box with `cover` leaves a narrow vertical slice
  of unreadable slides. Needs `object-fit:contain`, or an aspect-ratio setting, or auto-detection from
  `video.aspect_ratio`.
- Tap targets (`.nav-cta` at 12px font / `padding:9px 13px`, `.brand` at 10px font) and 9–11px text fall well below
  mobile norms.

### ⚙️ Cross-cutting (not counted in the 10): theme-editor & platform hygiene — **4 / 10**
- No `presets` in any section schema → sections can't be added from the editor; no `blocks` → FAQs, curriculum rows and
  testimonials can't be repeated/reordered by the merchant.
- No `config/settings_schema.json`, `config/settings_data.json` or `locales/en.default.json` (Shopify auto-generates
  the config files, but there are no brand-level settings, no favicon setting, no social links, no colour/typography
  controls).
- **`instructor_image_position` is exposed in the editor but never used** — it's not referenced in any Liquid template,
  and the CSS hard-codes `object-position:center center !important`, so the setting silently does nothing.
- Header/footer are legacy static `{% section 'course-header' %}` calls in `theme.liquid` rather than Shopify 2.0
  **section groups** (`sections/header-group.json` / `footer-group.json`).
- Missing templates: `404`, `search`, `page`, `collection`, `list-collections`, `blog`, `article`, `gift_card`,
  `password`, `customers/*`. Any non-homepage URL (including the pre-launch password page and every 404 from an ad) renders
  header + footer around an empty `<main>`.
- SEO: no favicon, no `<link rel="canonical" href="{{ canonical_url }}">`, hardcoded meta description instead of
  `{{ page_description }}`, no OG/Twitter tags, and **no JSON-LD** — a `Course` + `Product/Offer` + `FAQPage` + `Person`
  block would make the page eligible for rich results and is the highest-leverage SEO work available here.
- Liquid filter usage: `external_video_url` is passed `autoplay: <boolean>`, `muted: true`, `playsinline: true`. That
  filter forwards **host URL query params**, and YouTube/Vimeo expect string values (`autoplay=1`, `mute=1` for YouTube,
  `muted=1` for Vimeo, `loop=1`) — booleans render as `autoplay=true`, so external-video autoplay will likely not
  behave as intended (`playsinline=1` is added by `external_video_tag` automatically anyway). Shopify-hosted
  `video_tag` autoplay is fine.
- `{% schema %}` JSON in all three sections parses cleanly; `templates/index.json` is valid. No Liquid syntax errors
  found.

## What's genuinely good

1. **Speed and privacy by design.** No external fonts, no third-party scripts, no JS bundles, no app bloat. Correctly
   completed, this should score 95+ on Lighthouse mobile performance — rare, and it directly improves paid-traffic ROI.
2. **Right landing-page narrative.** Hero → proof → demo video → outcome → academy → curriculum → trainer → inclusions →
   price → FAQ is the correct order for a live cohort, and the copy is specific rather than generic.
3. **Real accessibility effort.** Skip link, landmarks, `aria-label`s, `aria-hidden` on decorative art, native
   `<details>` accordions, `prefers-reduced-motion` — better than many paid themes.
4. **Honest operations notes.** The README flags the compare-at-price, ANI-claim and video-rights risks proactively.
5. **Mobile-first intent is genuine.** The 749px block does the right things (column stacking, clamped type, capped
   media, overflow guards); the work just needs consolidating instead of layering.

## Method

Static analysis of all seven theme files:
- **Schema validation:** all three `{% schema %}` blocks parse as valid JSON (13 / 19 / 13 settings; no `presets`, no `blocks`).
- **Markup ↔ CSS reconciliation:** 119 classes defined, 47 used, **73 dead**, **1 used-but-unstyled** (`.mini-curriculum`),
  and `.eyebrow` has no base rule.
- **Link census:** 9 of 14 rendered `href` values are empty.
- **Cascade audit:** 107 `!important`, 11 `@media` blocks across breakpoints 900 / 749 / 600; confirmed
  `.bootcamp-v10` rules cannot match the `.bootcamp-v12` wrapper.
- **Template coverage** checked against Shopify's theme-architecture requirement for a matching template per page type.
- **Liquid filters** checked against Shopify's `video_tag`, `external_video_url` / `external_video_tag` and `image_tag`
  documentation.
- **Rendered output** produced by `audit-preview/render.py`, a minimal Liquid evaluator that applies each section's
  schema defaults and conditionals, reproducing the true out-of-the-box HTML (Shopify-injected `content_for_header`
  scripts excluded).
