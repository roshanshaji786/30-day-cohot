📱 MOBILE OPTIMISATION — pillar 3.7 / 10
8. Mobile layout correctness5 / 10 The @media(max-width:749px) block is competent: hero stacks to flex-column, illustration moves to order:2, H1 clamps to clamp(38px,10.7vw,52px), grids collapse, video caps at min(82vw,340px), overflow-wrap:anywhere prevents overflow, body{overflow-x:hidden}. But there are 5 stacked version layers (V6/V7/V10/V12 + photo-fix) with 107 !important declarations and three competing breakpoints (900 / 749 / 600) that contradict each other; the "overlap fix" just sets the hero art to opacity:.5 on mobile (looks washed-out/faded rather than designed); and the desktop layout is broken — all container padding/max-width lives under .bootcamp-v10 (.bootcamp-v10{max-width:1180px}, .bootcamp-v10 section{padding:52px 24px}) while the markup wrapper is <div class="bootcamp-v12">, so on any screen ≥750px sections are edge-to-edge with no padding.
9. Mobile performance & media weight4 / 10 Good: zero third-party scripts, zero webfonts, zero JS files at all; aspect-ratio prevents CLS; loading:'lazy' on the instructor image; image_tag auto-emits width/height + srcset; preload:'metadata' and playsinline on video (both already Shopify defaults). Bad: 23.5 KB unminified CSS of which 73 of 119 defined classes are dead (hero-card, steps, method-grid, tool-grid, curriculum, class-row, pricing-card, award-grid, final-cta, illustration…) — ~60% of the stylesheet; instructor image requested at width: 800 for a 280px box and logo at width: 280 for a 34px box, with no sizes attribute so phones download the largest candidate; backdrop-filter:blur(18px) on a sticky header is expensive on low-end Android; autoplay + loop on a full workshop video burns mobile data with no size cap or opt-in.
10. Mobile conversion ergonomics2 / 10 No sticky bottom buy bar (the single highest-ROI mobile element for a course page), the header CTA is dead, only 2 CTAs across ~8 screens of scrolling, and the empty 9:16 video box (≈600px tall) occupies the entire first screen below the hero before any offer detail. Critically, .video-placeholder{aspect-ratio:9/16} + object-fit:cover will crop a landscape workshop/screen-share recording down to a narrow vertical slice — screen recordings are unreadable. Needs object-fit:contain or an aspect-ratio setting. Tap targets and 9–11px text also fall below the 44px / 16px mobile norms.
⚙️ CROSS-CUTTING (not counted in the 10) — merchant & platform hygiene
Theme-editor experience4 / 10 No presets in any section schema → sections can't be added from the editor; no blocks → FAQ/curriculum/testimonials can't be repeated by the merchant; no config/settings_schema.json, config/settings_data.json or locales/en.default.json; instructor_image_position is exposed in the editor but never used in markup and the CSS forces object-position:center center !important, so the setting silently does nothing; header/footer are legacy static {% section %} calls instead of Shopify 2.0 section groups. Also missing: templates/404, search, page, collection, blog, article, gift_card, password, customers/*; no favicon; no <link rel="canonical" href="{{ canonical_url }}">; the meta description is hardcoded in theme.liquid so every page shares one description instead of {{ page_description }}; no OG/Twitter tags; no JSON-LD (Course, Product/Offer, FAQPage, Person) → zero rich-result eligibility.

What's genuinely good

Speed & privacy by design

No external fonts, no third-party scripts, no JS bundles, no app bloat. A correctly-completed version of this theme should score 95+ on Lighthouse mobile performance, which is rare and directly helps paid-traffic ROI.

Sensible landing-page narrative

Hero → proof → demo video → outcome → academy → curriculum → trainer → inclusions → price → FAQ is the right order for a live-cohort course, and the copy is specific (15 classes, 9 PM, Oct 1, Google Meet).

Real accessibility effort

Skip link, landmark elements, aria-labels, aria-hidden on decorative CSS art, native <details> accordions and a prefers-reduced-motion block — better than many paid themes.

Honest operations notes

The README flags the compare-at-price, ANI-claim and video-rights risks yourself. That's exactly the right instinct; it just needs to be enforced in the theme (legal links + substantiated claims).

Prioritised fix list

P0 Blocks all revenue — do before publishing

  • Add templates/product.json + a product section with a real {% form 'product' %} / buy-buttons block, plus templates/cart.json and a cart section. Or point CTAs at Shopify's Buy Button checkout.
  • Give every nav/footer/CTA link a working default URL (use all_products['handle'].url instead of a hardcoded string so it survives a handle change).
  • Add id anchors (#program #curriculum #instructor #faq) + scroll-margin-top:90px, or hide nav links that have no URL set.
  • Fix the desktop layout: port .bootcamp-v10 container/padding rules to .bootcamp-v12 (or rename the wrapper).
  • Add fallback content when no video/photo is uploaded — today the default state shows an empty black box.
  • Add refund/privacy/terms/contact links in the footer (needed for ad + gateway approval).

P1 Conversion multipliers

  • Sticky mobile buy bar: price + "Join now" fixed to the bottom, appears after the hero.
  • Mobile nav (hamburger or a scrolling chip row of anchors).
  • 3–6 testimonials with photos/names + a student-store screenshot wall + an alumni count.
  • Seats-left counter driven by real product.variants.first.inventory_quantity so the "first 25" claim is truthful and ad-safe.
  • Pull price from the product object (product.price | money, compare_at_price) and add a guarantee + payment/EMI reassurance near the CTA.
  • WhatsApp / Instagram / email contact buttons — high-intent for this market.
  • Fix the video: object-fit:contain or an aspect-ratio setting, plus a poster image.

P2 Quality, SEO & maintainability

  • JSON-LD for Course, Product/Offer, FAQPage, Person.
  • Dynamic {{ page_description }}, {{ canonical_url }}, OG/Twitter tags, favicon, 404/search/page templates.
  • Add a base .eyebrow rule; wrap the H1 accent word in <span>; add H3s.
  • Remove the 73 dead CSS classes, dedupe the 5 version layers and 107 !importants, minify (23.5 KB → ~7 KB).
  • Right-size images (instructor 560px + sizes, logo 120px), add :focus-visible styles, raise the minimum font size to 14px and fix the opacity:.55 contrast failure.
  • Convert hardcoded content into section blocks + presets; add locales/en.default.json and config/settings_schema.json; move header/footer to section groups; wire up or delete instructor_image_position.

Score after P0 + P1

  • Sales / Conversion: 3.0 → 8.0
  • User-Friendly / UX: 3.7 → 8.0
  • Mobile Optimisation: 3.7 → 8.5
  • Overall: 3.4 → ~8.1 / 10 — a fast, credible, mobile-first course storefront.

Audit method

Static analysis of all 7 theme files: schema JSON validity, markup-vs-CSS class reconciliation (119 defined / 47 used / 73 dead / 1 unstyled), link-href census (9 empty of 14), !important and media-query inventory, Liquid filter usage checked against Shopify's video_tag / external_video_tag / image_tag documentation, and template coverage checked against Shopify's theme-architecture requirement that "you need to have a matching template for any page type that you want to render". The render above was produced by audit-preview/render.py, a minimal Liquid evaluator that applies each section's schema defaults, so it reflects the true out-of-the-box output.
