AI × Shopify Business Bootcamp — Shopify Theme

SETUP
1. Create a Shopify store for course.roshanshaji.com.
2. Create a product with handle:
   ai-shopify-business-bootcamp
   Price: ₹2,999
   Compare-at price: ₹5,000
3. Upload this ZIP in Shopify Admin → Online Store → Themes → Add theme → Upload zip.
4. Publish the theme.
5. Connect course.roshanshaji.com to Shopify through the domain/DNS settings.
6. Replace the "YOUR PHOTO" placeholder in sections/main-course.liquid with the instructor photo.
7. Replace the UDS workshop placeholder with the authorized YouTube/Vimeo embed.
8. Review all legal, refund, payment and Shopify-offer wording before publishing.
9. Test checkout on mobile and desktop before ads.

IMPORTANT
- The ₹5,000 compare-at price should only be used if ₹5,000 is genuinely your standard/reference price.
- The Shopify introductory offer should be described according to the offer actually available when students register.
- Add your actual workshop video only if you have permission to publish it.
- This starter theme intentionally uses no external fonts or third-party scripts for speed and simplicity.
